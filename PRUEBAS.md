# Web de pruebas de La Porra del Cocido

Esta rama existe para mantener abierta una vista previa (Deploy Preview) en Netlify
con su propia urna de pruebas (`STORE_NAME=porra-pruebas`, `TEST_MODE=true`,
configuradas solo para el contexto *deploy-preview*).

**No fusionar.** Mantener la petición de cambios abierta mientras se quiera
tener la web de pruebas disponible.
